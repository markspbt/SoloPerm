# SoloPerm

**Simple, modular business software for macOS.**

SoloPerm helps small businesses, freelancers, and individuals manage their work without unnecessary complexity.

- Start with one free module.
- Add only the modules you need.
- Keep your data locally on your Mac.
- No subscriptions or recurring fees.
- Automatic module installation and updates.
- Import, export, and recovery capabilities.

## Available Modules

- **Bookkeeping** — Track income, expenses, and deductions.
- **Attachments** — Organize supporting documents with your records.
- **CSV Export** — Export your data for use elsewhere.
